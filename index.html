Overlay on top of games

Shortcut: Ctrl+Shift+P. Shows over borderless or windowed-fullscreen games (not exclusive fullscreen).
CPU temperature: Windows keeps it private from normal programs, and reading it needs a special driver, so this app does not install one. If you run the free HWiNFO (turn on Settings > Shared Memory Support), the temperature appears here automatically.
Game FPS: Windows does not let a program see another game's frame rate. MSI Afterburner (with RivaTuner) measures it, and this app shows it while RivaTuner is running and a game is open.
